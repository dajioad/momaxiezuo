# 墨码写作

> 本地运行、稿子不上云的沉浸式网文写作工具

一款面向网络小说作者的桌面写作软件。**所有稿件保存在本机**，AI 能力可选、可换、可关闭，不绑定任何平台账号。

## ✨ 特性一览

### 📝 专注写作

- **三栏工作台**：章节树 ｜ 沉浸式编辑器 ｜ AI 抽屉，可自由折叠
- **打字机滚动**：光标锁定屏幕中部，只在键盘输入时触发（粘贴/撤销不干扰）
- **限宽居中**：默认 720px 阅读宽度，长时间写作不易疲劳
- **10 套写作主题**：护眼米白 / 羊皮纸 / 雪白极简 / 豆沙绿 / 晴空蓝 / 樱花信笺 / 深夜黑 / 炭灰护眼 / 深海蓝 / 竹林夜，支持自定义配色
- **专注模式（F11）**：隐藏一切干扰，只剩下文字

### 📚 作品管理

- **章节树**：卷 / 章节两级结构，支持拖拽排序、跨卷移动
- **状态标记**：草稿（空心圆）/ 已完成（绿勾）
- **多选批量操作**：Ctrl/Shift 多选后批量移动、删除、标记状态
- **作品画廊**：网文 3:4 封面比例，支持上传自定义封面
- **回收站**：删除的作品先进回收站，可恢复或彻底删除

### 🛡️ 数据安全（铁律）

- **原子写入**：所有文件写入采用「临时文件 → fsync → os.replace」，断电不丢稿
- **崩溃恢复**：每 3 秒独立打一份草稿，比自动保存更可靠
- **历史快照**：应用排版 / 删除章节前自动生成快照，每章保留最近 20 份
- **一键备份**：所有作品 / 快照 / 词库 / 统计打包成 zip

### 🤖 AI 助手

- **9 家 AI 服务商**：DeepSeek、Kimi、智谱、通义、豆包、OpenAI、OpenRouter、硅基流动，以及任何 OpenAI 兼容端点
- **流式对话**：实时显示生成内容，可随时停止并保留已收内容
- **改写对比**：选中一段文本，AI 并排生成 3 个风格不同的改写版本
- **作品上下文自动注入**：发送请求时，AI 自动带上人物卡、词条、前几章梗概
- **AI 生成本章梗概**：一键总结当前章节，可编辑后写入
- **AI 提取新词条**：扫一章，自动提取新角色 / 地名 / 技能，勾选后入库
- **预设提示词**：续写 / 卡文锦囊 / 起名 / 开书灵感，可自定义、编辑、排序

### 🎨 写作辅助

- **符号面板**：省略号、书名号、装饰符、分隔线，支持"头部/尾部/两端/分隔"四种插入方式
- **高频词库**：按分类管理角色名 / 技能 / 地名 / 法宝，双击插入光标处
- **人物卡**：名字、别名、身份、性格、背景、关系、出场统计，一键插入正文
- **出场统计**：自动扫描全本，统计每个角色出场章节数、总提及次数、最后出场位置
- **词条高亮**：人物名 / 地名 / 技能名在正文中按分类颜色高亮，可自定义色

### 🧹 编辑工具箱

- **段落处理**：拆分长段 / 合并短行 / 空行统一 / 缩进统一
- **文本清洗**：行首行尾空白 / 空行压缩 / 不可见字符 / 复制残留（含 Markdown 标记）
- **格式统一**：标点 英↔中 / 引号风格 / 数字统一 / 全角半角
- **术语替换**：作品级查找替换，按章节分组列出所有匹配，逐条可勾选，支持导出对照表

### 📐 一键排版

- 规则勾选 → 差异预览 → 确认应用
- 应用前自动生成章节快照（铁律）
- 支持范围：仅当前章节 / 全书所有章节

### 🔍 校对

- **错别字检测**：连续字符、标点叠用、行号残留等规则
- **敏感词检测**：内置 + 自定义词库
- **自定义词库**：可添加错别字对、敏感词、忽略列表
- **批量导入**：支持 TXT / CSV / TSV / MD / JSON / DOCX 格式
- **全书校对**：一次扫全书，结果可勾选批量替换

### 📊 码字统计

- 今日字数 / 连续天数 / 累计字数 / 写作时速
- 全年热力图（GitHub 贡献图风格）
- 30 天趋势柱状图
- 每日目标进度

### 🚀 发布

- 一键跳转到 20+ 网文 / 内容平台的作家后台
- 支持自定义平台、隐藏预置平台
- **只跳转，不自动提交**，存稿仍由你手动粘贴

### 🔄 更新检查

- 启动后自动检查（每天最多一次，失败静默）
- 菜单「帮助 → 检查更新」可手动触发
- 支持主源 + 镜像源双源竞速

## 📦 安装

### 从发布版安装（推荐）

1. 前往 [Releases](https://gitee.com/momaxiezuo/ink-code-writing/releases) 页面

## 🎯 使用技巧

### 让人物名在正文中高亮

1. 侧栏「人物」标签 → 新建几个角色
2. 侧栏「高频词」标签 → 添加地名、技能、法宝
3. 回到正文，你会发现这些名字自动按分类颜色高亮
4. 每个分类的颜色都可以自定义（点分类旁的颜色按钮）

### 让 AI 知道你在写什么

不需要手动粘贴设定。**AI 会自动读取**：
- 作品名、作者、章节数
- 所有角色卡的名字、身份、别名、性格
- 各分类词条（地名、技能、法宝）
- 最近 3 章的梗概

所以你可以直接问 AI：「林墨在第五章的表现符合他的人设吗？」

### 快速统一全书术语

1. 工具 → 编辑工具箱 → 术语替换
2. 输入「王小明 → 王晓明」
3. 范围选「整部作品」，点预览
4. 结果按章节分组，每条可单独勾选
5. 点「应用到正文」，原稿自动快照

### 老稿乱码修复

1. 工具 → 批量工具 → 编码转换
2. 拖入乱码文件夹
3. 源编码选「自动识别」，目标编码选「UTF-8」
4. 转换前自动备份 `.bak.<时间戳>` 文件

## ❓ 常见问题

**Q：稿子会上传到服务器吗？**
A：不会。所有稿件保存在本机。AI 请求只在你主动点击发送时发生，且只发送你输入的内容和上下文摘要。

**Q：AI 助手如何收费？**
A：本软件不收取任何 AI 费用。你需要自己到服务商（如 DeepSeek）申请 API Key，按 token 由服务商直接计费。

**Q：换电脑了怎么办？**
A：用「作品 → 备份所有作品」打包成 zip，拷到新电脑解压到数据目录即可。注意 AI Key 不在备份里，需要重新填写。

**Q：能自动同步到云盘吗？**
A：可以。数据目录可以设置在 OneDrive / 坚果云等同步目录里。

**Q：为什么用本地存储而不是云？**
A：稿件是你最宝贵的资产。云服务可能涨价、可能关停、可能泄露。本地存储让你完全掌控自己的作品。

**Q：怎么更新软件？**
A：启动后会自动检查更新，有新版会弹窗提示。也可以在「帮助 → 检查更新」手动触发。

**Q：支持 Markdown 吗？**
A：支持导入导出 Markdown。正文编辑器是纯文本模式，因为它最适合长篇网文的写作场景。
