# 墨码写作

> 本地运行、稿子不上云的沉浸式网文写作工具

一款面向网络小说作者的桌面写作软件。**所有稿件保存在本机**，AI 能力可选、可换、可关闭，不绑定任何平台账号。

## ✨ 特性一览

### 📝 专注写作

- **三栏工作台**：章节树 ｜ 沉浸式编辑器 ｜ AI 抽屉，可自由折叠
- **打字机滚动**：光标锁定屏幕中部，只在键盘输入时触发（粘贴/撤销不干扰）
- **限宽居中**：默认 720px 阅读宽度，长时间写作不易疲劳
- **10 套写作主题**：护眼米白 / 羊皮纸 / 雪白极简 / 豆沙绿 / 晴空蓝 / 樱花信笺 / 深夜黑 / 炭灰护眼 / 深海蓝 / 竹林夜，支持自定义配色
- **专注模式（F11）**：隐藏一切干扰，只剩下文字
- **顺手的细节**：段首缩进三档可选（全角 / 半角 / 不缩进）、引号自动配对、`Ctrl+滚轮` 以光标为中心缩放、右键直接搜索选中文本；状态栏实时显示保存状态图标（金色转圈 / 绿色对勾 / 红色警告）
- **统一现代界面**：全站一套设计令牌（4px 间距栅格 / 9–12px 圆角 / 32px 控件高度），胶囊标签页、主次按钮分级（实底主操作 + 描边次操作）、细滚动条与细进度条、隐形悬停分隔条，浅色/深色主题表现一致

### 📚 作品管理

- **章节树**：卷 / 章节两级结构，支持拖拽排序、跨卷移动，每章实时显示字数
- **状态标记**：草稿（空心圆）/ 已完成（绿勾）
- **多选批量操作**：Ctrl/Shift 多选后批量移动、删除、标记状态；拖拽误操作可 `Ctrl+Z` 撤销
- **章节回收站**：删除的章节先进回收站，可恢复或彻底删除
- **作品画廊**：网文 3:4 封面比例，支持上传自定义封面
- **作品回收站**：删除的作品先进回收站，可恢复或彻底删除

### 🛡️ 数据安全（铁律）

- **原子写入**：所有文件写入采用「临时文件 → fsync → os.replace」，断电不丢稿
- **崩溃恢复**：每 3 秒独立打一份草稿，比自动保存更可靠
- **历史快照**：应用排版 / 删除章节前自动生成快照，每章保留最近 20 份
- **快照浏览器**：按作品浏览全部历史版本，双版本彩色差异对比，一键恢复，误删章节也能找回
- **一键备份**：所有作品 / 快照 / 词库 / 统计打包成 zip
- **定时自动备份**：默认每周在后台静默备份到数据目录 `auto_backups/`（可设每天 / 每周、保留 1–30 份自动清理），密钥与授权文件刻意不入包

### 🤖 AI 助手

- **8 家预置服务商**：DeepSeek、Kimi、智谱、通义、豆包、OpenAI、OpenRouter、硅基流动，另支持任何 OpenAI 兼容端点（中转站 / 本地模型）
- **流式对话**：实时显示生成内容（Markdown 气泡）；等待时气泡里显示"思考中"三点脉冲动效，首个 token 到达即刻切换为正文；可随时停止并保留已收内容；对话历史按作品保存，随时回看继续
- **改写对比**：选中一段文本，AI 并排生成 3 个风格不同的改写版本
- **作品上下文自动注入**：发送请求时，AI 自动带上人物卡、词条、前几章梗概
- **AI 生成本章梗概**：一键总结当前章节，可编辑后写入
- **AI 提取新词条 / 人物关系**：扫章节自动提取角色 / 地名 / 技能与角色关系，勾选后入库；人物关系支持「本地规则秒提取 + AI 补边」双通道，可按章节区间批量提取
- **墨灵试读**：以"老书虫读者"视角逐章模拟追读反馈（追读欲评分、章末钩子、弃读点），全书汇总开篇判断 / 节奏曲线 / 弃读风险与改进建议
- **小说转剧本**：一键改编为标准剧本 / 分场大纲 / 短剧分镜，结果直接复制
- **AI 输出字号**：12～20px 可调，长文阅读不累眼
- **预设提示词**：续写 / 卡文锦囊 / 起名 / 开书灵感，可自定义、编辑、排序

### 🩺 写作质量分析

- **追读体检**：开篇钩子、节奏、信息密度、爽点分布逐项打分，支持 AI 深度分析
- **一致性检查**：全书扫描形近 / 音近混淆的人物名（如「王小明 / 王晓明」）
- **人物关系图**：根据人物卡自动生成可视化关系图谱
- **伏笔追踪**：登记伏笔埋设 / 回收章节，AI 扫描提示未回收伏笔
- **发布前体检**：排版 + 校对 + 追读 + 一致性一条龙汇总，发书前最后一道关
- **质量中心**：墨灵试读与追读体检报告自动存入作品目录，随时回看、删除；逐章分数 / AI 深度结果都在，随作品备份一起带走（一致性扫描支持 3000 章长篇）

### 🎨 写作辅助

- **符号面板**：省略号、书名号、装饰符、分隔线，支持"头部/尾部/两端/分隔"四种插入方式
- **高频词库**：按分类管理角色名 / 技能 / 地名 / 法宝，双击插入光标处
- **人物卡**：名字、别名、身份、性格、背景、关系、出场统计，一键插入正文
- **出场统计**：自动扫描全本，统计每个角色出场章节数、总提及次数、最后出场位置
- **词条高亮**：人物名 / 地名 / 技能名在正文中按分类颜色高亮，可自定义色

### 🧹 编辑工具箱

- **段落处理**：拆分长段 / 合并短行 / 空行统一 / 缩进统一
- **文本清洗**：行首行尾空白 / 空行压缩 / 不可见字符 / 复制残留（含 Markdown 标记）

### 🧰 批量工具

- **文件名清理**：批量删除 / 替换文件名中的指定字符，保留扩展名

## 🎯 使用技巧

### 让人物名在正文中高亮

1. 侧栏「人物」标签 → 新建几个角色
2. 侧栏「高频词」标签 → 添加地名、技能、法宝
3. 回到正文，你会发现这些名字自动按分类颜色高亮
4. 每个分类的颜色都可以自定义（点分类旁的颜色按钮）

### 让 AI 知道你在写什么

不需要手动粘贴设定。**AI 会自动读取**：
- 作品名、作者、章节数
- 所有角色卡的名字、身份、别名、性格
- 各分类词条（地名、技能、法宝）
- 最近 3 章的梗概

所以你可以直接问 AI：「林墨在第五章的表现符合他的人设吗？」

### 快速统一全书术语

1. 工具 → 编辑工具箱 → 术语替换
2. 输入「王小明 → 王晓明」
3. 范围选「整部作品」，点预览
4. 结果按章节分组，每条可单独勾选
5. 点「应用到正文」，原稿自动快照

### 老稿乱码修复

1. 工具 → 批量工具 → 编码转换
2. 拖入乱码文件夹
3. 源编码选「自动识别」，目标编码选「UTF-8」
4. 转换前自动备份 `.bak.<时间戳>` 文件

## ❓ 常见问题

**Q：稿子会上传到服务器吗？**
A：不会。所有稿件保存在本机。AI 请求只在你主动点击发送时发生，且只发送你输入的内容和上下文摘要。

**Q：AI 助手如何收费？**
A：本软件不收取任何 AI 费用。你需要自己到服务商（如 DeepSeek）申请 API Key，按 token 由服务商直接计费。

**Q：换电脑了怎么办？**
A：用「作品 → 备份所有作品」打包成 zip，拷到新电脑解压到数据目录即可。注意 AI Key 不在备份里，需要重新填写。

**Q：能自动同步到云盘吗？**
A：可以。数据目录可以设置在 OneDrive / 坚果云等同步目录里。

**Q：用「备份所有作品」导出 zip 后换电脑，AI Key 还在吗？**

不在。备份**刻意不包含** `ai.dat`：

  · 该文件用**本机硬件指纹加密**，拷到新电脑也无法解密
  · 换机后重新粘贴一次 API Key 即可，作品 / 快照 / 词库 / 统计都在备份里

换机时的正确做法：

  1. 用「备份所有作品」导出 zip
  2. 记住原来的 AI Key（或从服务商后台复制一份）
  3. 新电脑上装好软件 → 恢复 zip → 重新粘贴 Key

**Q：软件收费吗？需要激活吗？**

软件全部功能永久免费，不需要激活码、不绑定设备、没有账号。
如果觉得好用，欢迎到爱发电（https://afdian.com/a/xiaoyu_tool ）请作者喝杯咖啡，
赞助完全自愿，不影响任何功能。

**Q：为什么用本地存储而不是云？**
A：稿件是你最宝贵的资产。云服务可能涨价、可能关停、可能泄露。本地存储让你完全掌控自己的作品。

**Q：怎么更新软件？**
A：启动后会自动检查更新，有新版会弹窗提示。也可以在「帮助 → 检查更新」手动触发。

**Q：支持 Markdown 吗？**
A：支持导入导出 Markdown。正文编辑器是纯文本模式，因为它最适合长篇网文的写作场景。

## 🛠️ 从源码运行

### 环境

- Python 3.10+（开发环境为 3.13）
- PySide6 6.11

### 安装依赖

```bash
pip install -r requirements.txt
```

核心依赖：PySide6、QtAwesome、requests、cryptography、Pillow、pypinyin（人名一致性检查的拼音通道，缺失时自动降级）。

### 运行

```bash
python main.py
```

### 运行测试

```bash
python -m pytest tests/
```

### 打包绿色便携版

```bash
# 安装 requirements.txt 中的 pyinstaller 后，直接运行打包脚本
python build.py
```

`build.py` 会调用 PyInstaller 生成 `dist\墨码写作\` 目录版绿色包（启动快、无需安装），
自动排除 torch / numpy / pandas 等无关大体积库，并复制图标、许可与说明文档、
清理 pyc、统计产物体积（目标 ≤ 200 MB）。
