桌宠素材目录。当前唯一服装为蓝鲸大肥鱼（whale/）。

whale/ 目录结构：
├── idle.png / happy.png / sleepy.png / thinking.png / writing.png
├── excited.png / shy.png / love.png / proud.png / worried.png / surprised.png
│   （各状态首帧，作为基础状态图）
└── {动作}/  （动作序列帧）
    ├── frame_00.png … frame_NN.png
    └── _durations.json   （每帧时长，毫秒）

支持的动作：idle / eating / drinking / pet_head / cleaning / playing / sleeping

换装菜单在 ui/pet_float.py 的 OUTFIT_DEFS。
